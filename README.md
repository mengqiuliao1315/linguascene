## 一、一句话，说清 LinguaScene 是什么

市面上的英语 App，大多在做两件事：背单词，或者刷题。

但它们都绕不开同一个尴尬——**到了真正要开口的那一刻，你还是不知道该说什么。**

LinguaScene 解决的正是这一环。它是一个**场景化英语对话平台**：把你扔进一个真实的语言情境里（在咖啡店点单、在机场值机、做一场面试），由 AI 扮演对话对象陪你一来一回地练。**你说得不对，它当场纠正；你表达得不够地道，它告诉你母语者会怎么说；你蹦出来的生词，它自动帮你收进词库，等你复习。**

练完之后，你拿到的不是一句「不错」，而是一份清清楚楚的学习报告、一批属于你自己的生词、和一套接下来该怎么复习的计划。

一句话：**别的工具让你「学」英语，LinguaScene 让你「用」英语——然后顺手把学习这件事也一并做完了。**

## 二、为什么值得用：六个非它不可的理由

### 1. 有对手、有剧本、有目标的对话

不是和一个空泛的聊天机器人瞎聊。每个场景都自带：AI 要扮演的角色（比如咖啡店店员）、开场白、学习目标、**重点句式**、**重点词汇**，以及一组会随对话推进逐条打勾的**任务**。

你不是在「聊天」，你是在**完成一个有进度条的练习**。对话走到哪一步、还剩哪些任务没完成，一目了然。

### 2. 每一句话，都有人接住、有人纠正

AI 的每次回复，都不只是「回你一句」。它同时带回来：

- **纠错**：指出你的语法、用词问题
- **更自然的表达**：母语者遇到这个意思会怎么说
- **新词汇**：从对话里自动挑出值得记的词，直接入库
- **教练备注**与**任务进度**

这是「即时反馈」该有的样子——**不用等老师批改，错误当场就归零。**

### 3. 生词不是抄下来的，是长出来的

传统背单词，是你从零硬记一份别人的词表。

LinguaScene 的词，来自**你自己的对话和阅读**。你在真实语境里遇到的词，自动进入生词本，带着它出现时的上下文，带着复习计划。**记住的成本更低，因为那是你亲身用过的词。**

### 4. 说得出，也听得见

- **语音输入**：点一下麦克风开口说，说完的英文直接进输入框，不用一个字一个字敲
- **语音朗读**：每句 AI 回复都能朗读，耳机一戴就是沉浸式听力
- **美式 / 英式发音**自由切换，还能预合成场景开场白——**你一进对话页，它就已经在说话了，零等待**

### 5. 阅读不只是读，是一整套消化流程

上传你自己的文章，一键「生成学习材料」：整篇分析、划词讲解、边写笔记边把笔记一键转成生词。读完还能**导出成 PDF**——原文、注释、笔记一起带走，**排版刻意做得紧凑省纸，方便打印出来反复看**。

### 6. 让你愿意每天都来

**XP、等级、连续打卡、成就、每日任务、排行榜**——一整套游戏化机制，加上养宠物的轻互动。学习平台最难的不是功能，是**让人第二天还想回来**。LinguaScene 把这件事设计进了产品里。

## 三、功能全景

| 模块                 | 能做什么                                                     |
| -------------------- | ------------------------------------------------------------ |
| **场景对话**（核心） | 选场景 → AI 角色对话 → 纠错 / 地道表达 / 生词入库 / 任务打勾 → 出学习报告 |
| **自由对话**         | 不限题目的 AI Tutor，想聊什么聊什么                          |
| **阅读与内容**       | 阅读材料、内置文章库、我的文章；整篇分析、划词分析、笔记、AI 建议、导出 PDF |
| **词汇闭环**         | 生词本（对话/阅读自动产生）+ 单词本（系统词书、闯关测验、每日目标、词书排行榜） |
| **语音能力**         | 语音合成朗读（美/英音）+ 语音识别输入（双通道，见下）        |
| **游戏化**           | XP、等级、连续打卡、成就、每日任务、排行榜、宠物养成         |
| **社交**             | 好友、私信、论坛（发帖 / 评论 / 点赞 / 置顶 / 图片）         |
| **仪表盘与个人中心** | 今日任务、推荐场景、待复习单词、学习活跃度热力图；资料与密码管理 |
| **自带模型**         | 用户可自配多家 AI 供应商，一键测试连通性、拉取模型列表，还能把配置分享给同学「采纳」 |

**9 个专职 AI Agent** 各司其职：场景对话主脑、纠错、词汇提取、单词短语讲解、句子结构分析、翻译、阅读注释、文章分析、学习报告。

## 四、技术可靠性与灵活部署（给管理者看）

- **AI 自由度**：平台不绑定任何一家大模型。统一 Provider 层支持 `openai` / `openai_responses` / `anthropic` / `gemini` 四种接入格式，**用户也可以自带 Key**，成本与效果自己权衡。
- **双通道语音识别**：既可用用户自配的高精度模型，也可用**服务端本地识别**——不要 Key、不花钱、不连外部 API。通道不可用时**如实报错，绝不偷偷替换**。
- **本地识别会「入乡随俗」**：做场景练习时，系统会把当前场景的重点句式和词汇作为提示喂给识别模型，**让识别结果优先往这个场景的词上靠，越练越准**。
- **稳定的工程底座**：Next.js 15 + React 19 前端、FastAPI + SQLAlchemy 后端、Alembic 数据库迁移、pytest 测试覆盖认证/对话/音频/词库/阅读/后台等模块。
- **开箱即用**：`mock` 模式下**不需要任何 API Key** 就能跑通全流程，方便演示与内测。

**账号安全**：平台默认**由管理员统一开通账号**，不开放自助注册——适合学校、机构、班级的受控场景。登录凭证存在会话级存储，**关掉浏览器即需重新登录**；管理员重置密码后，该用户已签发的登录凭证会立即失效。
