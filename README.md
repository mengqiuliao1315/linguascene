# LinguaScene 平台说明书

> **把「开口练英语」变成一件会上瘾的事。**
> 选场景 · 和 AI 角色对话 · 当场纠错 · 生词自动入库 · 复习巩固 · 游戏化激励 —— 一个完整的英语学习闭环。

***

## 一、一句话，说清 LinguaScene 是什么

市面上的英语 App，大多在做两件事：背单词，或者刷题。

但它们都绕不开同一个尴尬——**到了真正要开口的那一刻，你还是不知道该说什么。**

LinguaScene 解决的正是这一环。它是一个**场景化英语对话平台**：把你扔进一个真实的语言情境里（在咖啡店点单、在机场值机、做一场面试），由 AI 扮演对话对象陪你一来一回地练。**你说得不对，它当场纠正；你表达得不够地道，它告诉你母语者会怎么说；你蹦出来的生词，它自动帮你收进词库，等你复习。**

练完之后，你拿到的不是一句「不错」，而是一份清清楚楚的学习报告、一批属于你自己的生词、和一套接下来该怎么复习的计划。

一句话：**别的工具让你「学」英语，LinguaScene 让你「用」英语——然后顺手把学习这件事也一并做完了。**

***

## 二、为什么值得用：六个非它不可的理由

### 1. 有对手、有剧本、有目标的对话

不是和一个空泛的聊天机器人瞎聊。每个场景都自带：AI 要扮演的角色（比如咖啡店店员）、开场白、学习目标、**重点句式**、**重点词汇**，以及一组会随对话推进逐条打勾的**任务**。

你不是在「聊天」，你是在**完成一个有进度条的练习**。对话走到哪一步、还剩哪些任务没完成，一目了然。

### 2. 每一句话，都有人接住、有人纠正

AI 的每次回复，都不只是「回你一句」。它同时带回来：

- **纠错**：指出你的语法、用词问题
- **更自然的表达**：母语者遇到这个意思会怎么说
- **新词汇**：从对话里自动挑出值得记的词，直接入库
- **教练备注**与**任务进度**

这是「即时反馈」该有的样子——**不用等老师批改，错误当场就归零。**

### 3. 生词不是抄下来的，是长出来的

传统背单词，是你从零硬记一份别人的词表。

LinguaScene 的词，来自**你自己的对话和阅读**。你在真实语境里遇到的词，自动进入生词本，带着它出现时的上下文，带着复习计划。**记住的成本更低，因为那是你亲身用过的词。**

### 4. 说得出，也听得见

- **语音输入**：点一下麦克风开口说，说完的英文直接进输入框，不用一个字一个字敲
- **语音朗读**：每句 AI 回复都能朗读，耳机一戴就是沉浸式听力
- **美式 / 英式发音**自由切换，还能预合成场景开场白——**你一进对话页，它就已经在说话了，零等待**

### 5. 阅读不只是读，是一整套消化流程

上传你自己的文章，一键「生成学习材料」：**逐句分析**、划词翻译、边读边写笔记、把笔记一键转成生词。读完还能**导出成 PDF**——原文、注释、笔记一起带走，**排版刻意做得紧凑省纸，方便打印反复看**。（完整拆解见第三节「精读模块全解读」）

### 6. 让你愿意每天都来

**XP、等级、连续打卡、成就、每日任务、排行榜**——一整套游戏化机制，加上养宠物的轻互动。学习平台最难的不是功能，是**让人第二天还想回来**。LinguaScene 把这件事设计进了产品里。

## 三、精读模块全解读：把任意一篇英文，变成你的私人精读课

这是 LinguaScene 里最「重」的一个模块。它不是「能打开一篇文章的阅读器」，而是一整套**把生材料吃透**的工作流——

> **你上传 → 它逐句拆 → 你划词查 → 你写笔记 → 你导出带走。**

五步走完，一篇陌生的英文，就成了**属于你自己**的精读课。

### 3.1 上传即读书：你想读什么，就传什么

不必迁就平台提供的文章。

- **两种入口**：上传文件，或直接**粘贴文本**（正文粘进去就能存）
- **文件格式宽容**：TXT / MD / **PDF** / **DOCX** / **SRT** / **VTT** / JSON——论文、电子书章节、Word 讲义，甚至带时间轴的字幕文件都能进（单文件 ≤ 10MB）
- **自动抽正文**：PDF 抽取文字、DOCX 解开文档结构取正文；混在里面的**中文说明行会被自动过滤，只留英文正文**，不用你手动清洗（精读只解析英文，传非英文会被明确告知）
- **上传即就绪**：保存那一刻，「学习材料」就已生成，点开就能进精读
- **可分享**：写好的材料能一键「**公布给大家**」，进入共享材料库；别人打开你的文章，能看到原文、并做自己的批注

### 3.2 逐句分析：一句一句，把每一层都讲透

打开一份材料，第一件事是**自动切句 + 逐句解析**。

- **切得聪明**：按段落切分，遇到 `Mr.` `etc.` `U.S.` 这类缩写不会误断；`A.` `I.` 这种段落标记也不会被当成句子
- **每句给出六层信息**：
  - **中文翻译**——这句话在说什么
  - **主干**——句子骨架，长难句先抓主干
  - **重点单词**——带**词形还原**（running→run、children→child 收敛到原形）、音标、词性、释义
  - **固定搭配**——搭配 + 释义 + 例句
  - **语法点**——知识点 + 讲解 + 例句
  - **更自然的表达**——母语者会怎么说这个意思
- **流式输出，边算边看**：不是「整篇跑完才给你看」。骨架先排出来，**读完一句发一句**，第一句立刻就到——长篇材料也不用对着空页面干等
- **离线兜底、绝不作假**：模型没调通时，用**分级词表挑出超纲词**顶上，并**明确告诉你这是兜底结果**，而不是假装是 AI 分析
- **分析一次，下次秒开**：结果会缓存，重开同一篇不用再等

### 3.3 划词翻译与解析：看到哪不懂，划到哪就懂

这是精读页最顺手的部分。**在原文里划中任意词或短语**，工具条立刻浮出来：

- **查词** → 弹出词卡：中文释义、音标、词性、**语境义**、例句、常见搭配；旁边就是**朗读按钮**；卡片上直接能「**加入批注**」「**加入词库**」
- **划词实时解析**：把选中的词/短语**连同它所在的那句原文**一起交给解析器，产出**一条释义 + 一句可以直接采纳的笔记**——不是孤立地查词典，而是「这个词在这句话里是什么意思」
- **五种颜色随手标**：浮层里点颜色，就把这段划进批注
- **AI 建议标注**：不想自己挑？点一下「AI 建议标注」，它逐句指出**哪些词、搭配、结构值得标**，用虚线在场——**点一下即可采纳，也能「全部采纳」或「忽略」**。建议只提示、**不强行写进你的笔记**，采纳了才落库
- **每句可朗读**：句子右侧一个小喇叭，点一下朗读整句，还会**预取下一句的语音**，边听边读

### 3.4 添加笔记：把自己的理解，钉在原文上

看懂只是第一步，**留下痕迹**才是精读。

- **五种颜色批注**：生词、搭配、重点、疑问、自定义——用颜色把不同性质的标注分开
- **三种记法，怎么顺手怎么来**：① 划词点颜色直接标；② 句子下方「给这句加笔记」输入框；③ 浮层里写笔记再保存
- **可改、可删、不重复**：释义与备注能二次编辑（Ctrl+Enter 保存），颜色随时改，不想要就删；同一句里同一个词**自动去重**，不会重复记
- **一键变成生词**：任何一条批注都能「**加入词库**」，带着它的语境和例句进入你的个人词库——**在阅读里遇到，就在阅读里记住**
- **侧栏批注总览**：右栏汇总本页全部批注，**按颜色筛选**，点一条就跳到对应句子
- **遮罩复习**：开启后所有批注**被挖空遮住**，点一下才揭示——一篇标满的文章，**立刻变成一份自测题**

### 3.5 导出 PDF：把精读成果装进口袋

读完、标完，一键「**导出 PDF**」。

- **左原文、右批注**：原文里批注**原位高亮**（圆角底色、按颜色区分），右侧栏列出**每句的重点词/搭配 + 释义 + 你自己的笔记**，左侧带**行号**
- **页眉页脚齐全**：页眉是 `LINGUASCENE 精读` 抬头，标注作者、等级、句数、批注数；页脚自动页码
- **为「打印」而生**：排版**刻意做得紧凑**（小边距、11pt 行距），**不放背景色块、不加彩色竖条**——用最少的纸装下最多的内容，方便打印出来随身翻
- **中文不乱码**：自动匹配系统中文字体（Windows 微软雅黑/等线、Linux Noto/文泉驿、macOS PingFang），跨平台导出中文释义都正常

**一句话收束这一节**：别的工具让你「读」文章，LinguaScene 让你**把一篇文章彻底变成自己的**——分析过、标注过、能复习、能打印、能带走。

## 五、技术可靠性与灵活部署（给管理者看）

- **AI 自由度**：平台不绑定任何一家大模型。统一 Provider 层支持 `openai` / `openai_responses` / `anthropic` / `gemini` 四种接入格式，**用户也可以自带 Key**，成本与效果自己权衡。
- **双通道语音识别**：既可用用户自配的高精度模型，也可用**服务端本地识别**——不要 Key、不花钱、不连外部 API。通道不可用时**如实报错，绝不偷偷替换**。
- **本地识别会「入乡随俗」**：做场景练习时，系统会把当前场景的重点句式和词汇作为提示喂给识别模型，**让识别结果优先往这个场景的词上靠，越练越准**。
- **稳定的工程底座**：Next.js 15 + React 19 前端、FastAPI + SQLAlchemy 后端、Alembic 数据库迁移、pytest 测试覆盖认证/对话/音频/词库/阅读/后台等模块。
- **开箱即用**：`mock` 模式下**不需要任何 API Key** 就能跑通全流程，方便演示与内测。

**账号安全**：平台默认**由管理员统一开通账号**，不开放自助注册——适合学校、机构、班级的受控场景。登录凭证存在会话级存储，**关掉浏览器即需重新登录**；管理员重置密码后，该用户已签发的登录凭证会立即失效。
